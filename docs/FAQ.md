# 常见问题

## 转换相关

### 转出来的文件里没有歌名/歌手？

分两种情况：

- **网易云 `.ncm`**：会写入标签（ID3v2.3 或 Vorbis Comment）。如果显示为空，说明源文件的元信息段是空的，不是转换出错。
- **QQ 音乐 / 酷我**：这些格式**自带标签**，本工具只做解密、不重写标签。如果读不到，会用原文件名命名，音频本身仍然是完整的。

### 提示「需联网取密钥」是什么意思？

QQ 音乐 **19.57 及以上版本**导出的文件改用 `musicex` 尾部格式，密钥不再保存在文件里，必须登录客户端向服务器请求。

本工具**不做任何联网请求**，所以这类文件解不了。这属于刻意不支持，不是故障。

两个变通办法：
1. 用旧版本客户端（≤ 19.51）重新下载
2. 用其它能联网取密钥的工具处理这一批

### 提示「文件损坏」或「密钥错误」？

| 错误码 | 含义 |
|---|---|
| `E_FORMAT` | 扩展名对，但文件内容不是该格式（可能被改过名，或下载不完整） |
| `E_CORRUPT` | 结构解析失败：文件被截断、拷贝过程中损坏，或不是标准文件 |
| `E_KEY` | 找不到密钥：酷我文件里没有可用的静音段，或 QQ 文件尾部结构不认识 |
| `E_EKEY` | 需要联网取密钥（见上一条） |
| `E_IO` | 读写失败：目标目录不可写、磁盘满、文件被占用 |

### 为什么有些文件在别的工具能转，这里不行？

反过来也成立。各家实现覆盖的格式变体不完全一样。遇到这种情况，请开一个 Issue 并附上：

- 文件扩展名
- 界面上的错误码
- 文件大小（不需要提供文件本身）

### 能转成 MP3 吗？

**不能。** 本工具只把加密的文件还原成它**原本**的格式：源是 FLAC 就出 FLAC，源是 OGG 就出 OGG。格式互转需要音频编码器，不在本项目范围内。

### 转出来的文件在哪？

默认写在**源文件旁边**。点工具栏的「输出」可以改成别的目录，详情面板里能看到完整输出路径（点一下可复制）。

## 使用问题

### 双击没反应 / 窗口一闪就没了

先看日志：

```
%LOCALAPPDATA%\com.tuneport.app\tuneport-startup.log
```

常见原因：
- 缺少 WebView2 运行时（Win10 1803+ / Win11 默认自带，极老的系统需要手动装一次）
- 程序放在受限目录（例如某些安全软件保护的路径），界面会提示「当前是受限运行环境」

### 杀毒软件报毒 / 提示「未知发布者」

exe 没有数字签名，SmartScreen 或杀软可能提示。点「更多信息 → 仍要运行」即可。

想彻底消除这个提示需要购买代码签名证书（每年数千元），个人项目一般不做。

### 点了「开始」但文件没动

确认这三件事：

1. 有没有点「开始」（不是只把文件拖进来）
2. 筛选器是不是停在「失败」上（切回「全部」看看）
3. 状态栏有没有报错提示

### 转换中途关掉程序，进度会丢吗？

不会。列表和每个文件的状态会自动存进 `queue.json`，重开程序会提示「已恢复 N 个文件」，已完成的保持完成，没转的继续等。

### 试听没声音

先在系统里确认默认输出设备正常，再确认这个文件的格式你的系统能播（FLAC / MP3 / OGG 都支持）。如果播放条出现了但没声音，多半是设备或音量问题，不是转换问题。

## 隐私与安全

### 会不会上传我的文件？

**不会。** 全程离线：不联网、不上传、不下载任何内容。可以断网使用。

### 会不会改动我的源文件？

**不会。** 源文件只读，输出写到新文件。

### 数据存在哪？卸载后会残留吗？

```
%LOCALAPPDATA%\com.tuneport.app\   → 浏览器缓存 + 启动日志
%APPDATA%\com.tuneport.app\        → settings.json（设置）、queue.json（列表）
```

卸载会删掉程序目录，但上面两个数据目录会保留（和大多数软件一样）。不需要了可以手动删除。

## 其它

### 支持 Mac / Linux 吗？

目前只提供 Windows 产物。代码本身基于 Tauri，理论上跨平台，但没有验证过，也没有构建脚本。

### 支持酷狗 / 咪咕 / Apple Music 吗？

- **酷狗**：`.kgm` 技术上可行，但需要从客户端提取的密钥表，本项目不做
- **咪咕、汽水音乐**：格式资料极少，未实现
- **Apple Music / Spotify**：属于真正的 DRM，密钥由服务器按会员授权下发，不支持

### 可以二次开发吗？

可以，[MIT 协议](https://github.com/) 允许修改和再分发。新增格式请参考 `core-rs/tests/` 里的端到端测试写法，务必附带**合成样本**测试。
