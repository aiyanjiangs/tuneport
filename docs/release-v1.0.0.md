# TunePort v1.0.0

把音乐客户端下载到本地的音频文件，还原成通用的 MP3 / FLAC / OGG。全程离线，不联网、不上传、不改动源文件。

## 支持格式

| 平台 | 扩展名 |
|---|---|
| 网易云音乐 | `.ncm` |
| QQ 音乐（旧） | `.qmc` `.qmc0` `.qmc2` `.qmc3` `.qmcflac` `.qmcogg` |
| QQ 音乐（新） | `.mflac` `.mflac0` `.mflach` `.mgg` `.mgg0` `.mgg1` `.mggl` |
| 酷我音乐 | `.kwm` |

## 亮点

- **流式解密**：ncm 按 1 MB 分块边解边写，转 4 GB 的库也不会吃满内存
- **标签完整**：ncm 会写入 ID3v2.3 / Vorbis Comment；其余格式自带标签，只解密不破坏
- **断点续跑**：中途关掉程序，重开自动接上，已完成的不会重转
- **失败可重试**：失败行标红置顶，单个文件重试不影响整批
- **内置试听**：转换完直接播放，不落地临时文件
- **6.4 MB 单文件**：无运行时依赖（除系统自带 WebView2），启动快

## 下载

| 文件 | 说明 |
|---|---|
| `TunePort-1.0.0-x64-setup.exe` | 安装版，装到用户目录，**不需要管理员权限** |
| `TunePort-1.0.0-portable.zip` | 绿色版，解压即用，不写注册表 |

系统要求：64 位 Windows 10 / 11。

## 已知限制

- 不支持 QQ 音乐 ≥ 19.57 的 `musicex` 格式（密钥不存于文件，需联网获取；**本项目刻意不做联网请求**）
- 不支持酷狗 `.kgma`、咪咕等格式
- 不做转码、不做封面嵌入
- exe 未签名，首次运行可能触发 SmartScreen，点「仍要运行」即可

## 隐私

全程离线：不联网、不上传、不下载任何内容。可以断网使用。源文件只读。
